# Plantillas

Aquí vive lo que ya no vuelves a pensar desde cero.

Cada archivo de esta carpeta es un texto que funcionó y que puedes reusar: el
mensaje de seguimiento que sí contestan, la cotización que cierras, el mensaje
de bienvenida que mandas cuando entra un cliente nuevo.

`/siguiente-nivel` escribe aquí cada vez que convierten una tarea repetitiva en
algo que se resuelve solo. También puedes guardar las tuyas a mano: crea un
archivo con un nombre corto y en minúsculas, sin acentos y sin eñe.

Para usar una, dile a tu asistente: "usa la plantilla de seguimiento con este
cliente".
